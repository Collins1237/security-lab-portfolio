## Objective

Demonstrate how an attacker turns stolen password hashes back into plaintext passwords, and show which password choices resist it — the evidence base for a password-policy recommendation.


## Tools used

- `md5sum` — build sample hashes (simulating a breached database)
- John the Ripper — dictionary + rule-based cracking

## Methodology

**Step 1 — Obtain hashes.** Simulated a breached database of unsalted MD5 hashes (`target_md5.txt`). Note alice and grace share a hash — identical unsalted hashes reveal password reuse.

**Step 2 — Dictionary + rules attack.** Ran John the Ripper against the hashes with a wordlist and mangling rules.

_Crack the hashes_

```console
$ john --format=raw-md5 --wordlist=/usr/share/john/password.lst --rules target_md5.txt 2>&1 | grep -viE 'proceeding|press|warning: detect|openmp|input encoding'
Loaded 6 password hashes with no different salts (Raw-MD5 [MD5 128/128 AVX 4x3])
123456           (bob)
password         (alice)
qwerty           (carol)
letmein          (dave)
4g 0:00:00:00 DONE (2026-10-12 19:05) 200.0g/s 7842Kp/s 7842Kc/s 15723KC/s Xxxing..Sssing
Warning: passwords printed above might not be all those cracked
Use the "--show --format=Raw-MD5" options to display all of the cracked passwords reliably
Session completed
```

_Show everything cracked_

```console
$ john --show --format=raw-md5 target_md5.txt 2>/dev/null
alice:password
grace:password
bob:123456
carol:qwerty
dave:letmein

5 password hashes cracked, 2 left
```


## Findings

- **5 of 7** passwords cracked, most in under a second (~5M guesses/sec on a laptop CPU; a GPU does billions).

- The long passphrase and the random 15-char password survived — length beat 'complexity'.

- Password reuse (alice/grace) was visible directly from the unsalted hashes.


## Remediation / recommendations

- Store passwords with a slow, salted algorithm (bcrypt / argon2), never MD5/SHA-1.
- Enforce length over complexity — passphrases of 15+ characters.
- Ban reuse and common passwords; deploy a password manager + MFA.

## What I learned (Security+ / pentest concepts)

- Hashing vs. encryption; salting and why it defeats reuse detection + rainbow tables.
- Work factor / slow hashes make offline cracking impractical.
- Dictionary → rules → brute/mask attack progression; why length wins.
